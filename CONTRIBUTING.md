# Contributing

## Commit Messages

Follow the [Conventional Commits Standard](docs/standards/conventional-commits.md) for all commit messages.

## Scope Vocabulary

This repository defines the following optional scopes:

- `checkstyle` - Checkstyle configuration in `checkstyle/`.
- `findbugs` - FindBugs configuration in `findbugs/`.
- `pmd` - PMD rulesets in `pmd/`.
- `ide` - IDE configuration in `ide/`.
- `prettier` - Prettier configuration in `packages/prettier-config/`.
- `standards` - Standards in `docs/standards/`.
- `decisions` - Decision records in `docs/decisions/`.
- `reference` - Reference documentation in `docs/reference/`.
- `runbooks` - Runbooks in `docs/runbooks/`.
